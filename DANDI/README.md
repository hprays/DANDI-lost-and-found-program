# DANDI 분실물 찾기 프로그램

> **단디(DANDI)** — 단국대학교 캠퍼스에서 잃어버린 물건을 찾고, 주운 물건을 등록하는 **분실·습득물 웹 서비스**입니다.

캠퍼스 곳곳에서 발견된 습득물을 한곳에서 모아 보여 주고, 본인 물건이 맞다면 **수령 QR**로 관리실에서 안전하게 찾아갈 수 있게 돕습니다.

---

## 이 웹은 어떤 서비스인가요?

학교 안에서 물건을 잃어버렸을 때, 예전처럼 건물마다 돌아다니며 “혹시 보셨나요?” 하고 물어보기 어렵죠.  
**단디**는 그 과정을 웹으로 옮긴 서비스입니다.

| 역할 | 할 수 있는 일 |
|------|----------------|
| **분실한 학생** | 홈에서 물건을 검색하고, 내 물건이면 수령 QR을 받아 관리실에서 찾아갑니다. |
| **습득한 학생** | 사진·장소·시간을 적어 분실물을 신고하고, 관리자 확인을 기다립니다. |
| **관리자(학생회·관리실)** | 신고를 검수하고, 습득물을 등록·수정하며, 수령 시 QR로 본인 확인을 합니다. |

로그인은 **단국대 이메일(`@dankook.ac.kr`)** 로만 가능합니다. 학교 구성원 전용 서비스라고 보시면 됩니다.

---

## 이렇게 쓰면 됩니다 (분실한 경우)

1. **로그인** — 학교 이메일로 가입·로그인합니다.  
2. **홈에서 찾기** — 카테고리(전자기기, 지갑, 신분증 등), 건물, 키워드로 습득물 목록을 봅니다.  
3. **상세 확인** — 사진, 습득 장소·시간, 보관 장소를 확인합니다.  
4. **수령 QR 발급** — “내 물건이 맞다”고 판단되면 상세 페이지에서 **수령 QR**을 받습니다. (유효 시간 있음)  
5. **관리실 방문** — 지도에서 가까운 관리실 위치를 보고, QR을 보여 주면 담당자가 본인 확인 후 수령 처리합니다.  
6. **완료** — 수령이 끝나면 홈 목록에 **수령완료** 표시가 붙고, DB에도 기록이 남습니다. (삭제되지 않음)

습득물은 **관리자가 검수·습득 완료 처리한 뒤**에만 홈 목록에 올라옵니다. 그 전에는 “검수 중” 상태로만 보입니다.

---

## 이렇게 쓰면 됩니다 (주운 경우)

1. **분실물 등록** 메뉴에서 사진, 물품명, 습득 일시·장소를 입력합니다.  
2. 필요하면 **AI(Vision)** 로 사진에서 물품 정보를 추출하는 기능을 쓸 수 있습니다.  
3. 제출하면 **관리자 검수 대기** 상태가 됩니다.  
4. 관리자가 확인 후 습득 완료 처리하면, 다른 학생들이 홈에서 볼 수 있습니다.

## 주요 기능 한눈에

### 실시간 습득물 목록 (홈)
- 카테고리·건물 필터, 키워드 검색  
- 습득 완료된 분실물만 카드 형태로 표시  
- **수령이 끝난 물건**은 물품명 옆에 **수령완료**(빨간 글씨)로 구분  

### 분실물 상세 & AI 수령 안내
- 습득 위치, 시간, 보관 장소 확인  
- 물품 종류에 맞춘 **수령 시 준비물·주의사항**을 AI가 짧게 안내 (예: 신분증 지참 여부)  

### 수령 QR
- 본인 물건일 때만 QR 발급  
- 마이페이지 **「내 수령 QR」** 에서 발급 내역·사용 여부 확인  
- 관리자는 QR 스캔 또는 **수령 코드 직접 입력**으로 인증  

### 캠퍼스 지도
- 관리실 위치, 운영 시간, 연락처를 지도에서 확인  

### 마이페이지
- 내 신고·처리 기록  
- **관심 키워드** 등록 → 비슷한 분실물이 올라오면 알림(설정 시)  
- 수령 QR 목록  

### Q&A 챗봇
- 홈 화면 플로팅 버튼 — 수령 절차, 운영 시간 등 자주 묻는 내용을 짧게 답변  

### 관리자 화면 (`/admin`)
- 분실 신고 **검수** (승인·반려·습득 완료)  
- 관리자 **직접 분실물 등록** (사진·Vision·보관 장소)  
- 등록된 물품 **수정·삭제**  
- **수령 인증** (QR / 코드 입력) — 완료 시 `RECEIVED` 상태로 저장

## 누구를 위한 웹인가요?

- **단국대 재학생** — 분실물 찾기, 습득물 신고, 수령 QR  
- **학생회·분실물 담당 관리자** — 검수, 등록, 수령 처리  
- **개발·운영** — 프론트(이 저장소) + Spring Boot 백엔드(`DANDI_Backend`, API `8080`) + Firebase 인증  

---

## 기술 구성 (개발자용)

| 구분 | 내용 |
|------|------|
| 프론트 | Next.js (App Router), React, Tailwind CSS |
| 인증 | Firebase (`@dankook.ac.kr`) |
| API | `NEXT_PUBLIC_API_BASE_URL` (기본 `http://localhost:8080`) |
| 지도 | Google Maps |
| AI | 수령 안내·챗봇·Vision (OpenAI / Gemini 등 환경 변수 설정) |

### 로컬 실행

```bash
cd DANDI
cp .env.example .env.local   # 값 채우기
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` — 백엔드는 별도로 `8080`에서 실행해야 API·로그인·목록이 정상 동작합니다.
